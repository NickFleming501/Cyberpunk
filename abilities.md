# Fähigkeiten

## Übersicht

Kategorie     | Fähigkeit             | Verwendung
--------------|-----------------------|-------------------------------------------------------------------------
Kommunikation | Beeinflussen          | Verführen, Einschüchtern, Anfreunden, Ablenken, Nerven, etc.
<br/>         | Täuschen              | Lügen, Betrügen, Verstellen, Dinge fälschen
<br/>         | Kontakte              | Verfügbarkeit und Qualität von Kontaktpersonen, die der Charakter kennt
Kampf         | Schusswaffen          | Herumballern
<br/>         | Nahkampf              | Draufhauen
<br/>         | Taktik                | Taktiken überlegen, Befehle geben
Tech          | Software[¹](#faehigkeiten-1)             | Hacking an Computern
<br/>         | Hardware[²](#faehigkeiten-2)             | Cyborgs und Drohnen, Sicherheitstechnik 
<br/>         | Fahrzeuge             | Fahrzeuge steuern, reparieren, verstehen
Wissen        | Chemie[²](#faehigkeiten-2)               | Sprengstoffe herstellen, Bomben entschärfen, Chemie-Gedöns
<br/>         | Medizin[²](#faehigkeiten-2)              | Wunden verarzten, Aufputschmittel herstellen
<br/>         | Recherche             | Sammeln und Auswerten von Informationen
PSI           | Manipulation[³](#faehigkeiten-3)         | Erinnerungen ändern, Gefühle auslösen, Kontrolle übernehmen
<br/>         | Fühlen[³](#faehigkeiten-3)               | Gedankenlesen, Emotionen wahrnehmen, Personen spüren
<br/>         | Konzentration         | Stress abbauen, Manipulation erschweren oder umkehren, Mentale Aufgaben erleichtern
Sonstiges     | Heimlichkeit          | Verstecken, Schleichen, Taschendiebstahl
<br/>         | Parkour               | Klettern, Abseilen, Parkour
<br/>         | Charakterhintergrund[⁴](#faehigkeiten-4) | Wissen aus vorherigen Erfahrungen. **Startwert ist 1**

::: {#faehigkeiten-1}
_¹ Benötigt einen entsprechenden Zugangspunkt_
:::

::: {#faehigkeiten-2}
_² Benötigt entsprechendes Werkzeug oder ein Labor/Werkstatt_
:::

::: {#faehigkeiten-3}
_³ Benötigt ein PSI-Implantat_
:::

::: {#faehigkeiten-4}
_⁴ Der Charakterhintergrund muss individuell festgelegt werden. Der Startwert zählt nicht für die Mindestpunkte pro Kategorie._
:::
